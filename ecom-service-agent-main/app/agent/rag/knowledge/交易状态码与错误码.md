# 并夕夕 交易状态码与系统错误码

## 一、订单状态码

| 状态码 | 中文名称 | 说明 |
|--------|----------|------|
| ORD-PENDING | 待支付 | 订单已创建，等待用户付款。30分钟内未支付自动取消 |
| ORD-PAID | 已支付 | 支付成功，等待商家确认并发货 |
| ORD-CONFIRM | 商家已确认 | 商家已确认订单，准备发货 |
| ORD-SHIPPED | 已发货 | 商品已出库，物流运输中 |
| ORD-DELIVERED | 已签收 | 用户已签收商品，7天后自动确认收货 |
| ORD-COMPLETE | 已完成 | 交易完成，评价期开启 |
| ORD-CANCEL | 已取消 | 订单被取消（用户取消/超时未付/商家取消） |
| ORD-REFUND | 退款处理中 | 退款申请已提交，审核中 |
| ORD-REFUNDED | 已退款 | 退款已完成，款项已退回 |

## 二、支付错误码

| 错误码 | 含义 | 解决方案 |
|--------|------|----------|
| PAY-ERR-1001 | 余额不足 | 更换支付方式或充值后重试 |
| PAY-ERR-1002 | 银行卡受限 | 联系发卡行解除限制 |
| PAY-ERR-1003 | 支付密码错误(3次) | 24小时后自动解锁或通过人脸重置 |
| PAY-ERR-1004 | 风控拦截 | 需联系客服提交身份验证材料 |
| PAY-ERR-1005 | 网络超时 | 检查网络后重试，已扣款将在15分钟内退回 |
| PAY-ERR-1006 | 优惠券过期 | 重新选择有效优惠券或放弃使用 |
| PAY-ERR-1007 | 花呗额度不足 | 降低分期数或更换支付方式 |

## 三、物流异常码

| 异常码 | 含义 | 触发条件 |
|--------|------|----------|
| LOG-ERR-2001 | 揽收超时 | 商家发货后48小时未揽收 |
| LOG-ERR-2002 | 运输超时 | 轨迹超过72小时未更新 |
| LOG-ERR-2003 | 派送失败(3次) | 连续3次派送无人签收 |
| LOG-ERR-2004 | 包裹破损 | 中转扫描时发现外包装破损 |
| LOG-ERR-2005 | 包裹丢失 | 快递公司确认包裹遗失 |
| LOG-ERR-2006 | 地址不详 | 收货地址无法定位到具体门牌号 |
| LOG-ERR-2007 | 拒收退回 | 用户拒收，包裹原路退回 |

## 四、退款状态码

| 状态码 | 含义 |
|--------|------|
| RFD-INIT | 退款申请已提交 |
| RFD-REVIEW | 商家审核中（24小时内） |
| RFD-APPROVE | 审核通过，待退货/待退款 |
| RFD-REJECT | 审核驳回 |
| RFD-RETURN | 退货中，等待仓库签收 |
| RFD-QUALITY | 质检中 |
| RFD-DONE | 退款完成 |
