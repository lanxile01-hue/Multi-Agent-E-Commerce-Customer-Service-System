# 数据安全规范

## 一、敏感数据识别

个人身份信息、认证凭据、财务信息、客户合同和未公开业务数据属于敏感数据。处理前必须确认用途、范围、保存期限和访问人员。

## 二、脱敏与日志

日志和监控默认不得记录完整手机号、身份证号、令牌、密码或原始合同内容。调试需要样本时使用脱敏数据，并限制留存时间。

## 三、存储与传输

敏感数据应使用批准的加密存储和传输方式。禁止将生产数据复制到个人电脑、个人网盘或未审批的第三方 AI 工具。

## 四、数据事件

发现误传、越权访问或疑似泄露时，不要自行删除证据，应立即停止扩散并联系安全团队。事件记录应包含时间、范围、受影响系统和已采取措施。
