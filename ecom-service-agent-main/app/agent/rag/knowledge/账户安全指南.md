# 并夕夕 账户安全指南

## 一、账户注册与认证

### 1.1 注册方式
- **手机号注册**：支持中国大陆手机号一键注册
- **第三方登录**：微信、支付宝快捷授权登录（首次需绑定手机号）
- **邮箱注册**：支持主流邮箱，但需额外绑定手机号以完成实名

### 1.2 实名认证
为保障账户安全和大额支付，建议完成实名认证。认证方式：
- **银行卡认证**：绑定本人名下储蓄卡，银行验证姓名+身份证号
- **人脸认证**：通过支付宝/微信人脸识别完成
- **企业认证**：需营业执照+法人身份证+对公账户验证

### 1.3 账户等级
- 未认证：单笔支付限额2000元，日累计5000元
- 已认证（个人）：解限，可正常使用全部功能
- 已认证（企业）：额外支持对公转账、增值税专票、子账户管理

## 二、安全设置

### 2.1 登录保护
- 开启登录验证：每次新设备登录需短信验证码确认
- 设备管理：可在「账户安全→已登录设备」中查看并踢除可疑设备
- 登录记录：保留近30天登录IP、设备、时间记录

### 2.2 支付保护
- 支付密码：6位数字密码，与登录密码独立
- 指纹/面容支付：在支持设备上可开启生物识别支付
- 免密支付限额：小额免密单笔上限200元，日累计500元，可自定义调整

### 2.3 安全提醒
- 异地登录提醒：检测到异地IP登录，实时短信+站内信通知
- 风险支付拦截：大额支付或异常设备支付触发人工审核
- 密码修改提醒：密码修改后全设备强制重新登录

## 三、账户异常处理

### 3.1 密码找回
- 手机号可用：通过短信验证码重置密码，即时生效
- 手机号停用：提交身份证正反面照片+手持照片，2个工作日内审核
- 邮箱可用：通过邮箱验证链接重置

### 3.2 账户被盗
如怀疑账户被盗，请按以下步骤处理：
1. 立即修改登录密码和支付密码
2. 解绑所有支付方式
3. 在「账户安全→紧急冻结」冻结账户
4. 联系客服，提供被盗时间线
5. 如发生未授权交易，拨打110报警并保存回执

### 3.3 账户恢复
冻结账户可在「账户安全→申请恢复」中解除，需重新完成身份验证。如有未授权交易纠纷，需等待平台安全部门调查完成后（3-5个工作日）方可恢复。

## 四、隐私与数据

### 4.1 数据保护
并夕夕遵守《个人信息保护法》和《数据安全法》。您的个人信息仅用于订单处理、客户服务、法律合规用途。不会未经授权出售或共享您的个人信息。

### 4.2 账户注销
可在「设置→账户安全→注销账户」提交申请。注销条件：
- 无未完成订单
- 无未处理纠纷/投诉
- 无余额需提现
- 已使用的优惠券/积分不退还

注销后有30天冷静期，期间可联系客服恢复账户。30天后数据永久删除。

### 4.3 数据导出
可在「设置→隐私→数据导出」申请导出您的订单记录、收货地址、评价记录。导出格式为CSV/JSON，3个工作日内发送至注册邮箱。
