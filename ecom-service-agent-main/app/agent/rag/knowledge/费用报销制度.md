# 费用报销制度

## 一、适用范围

本制度适用于因公出差、客户拜访、培训和经批准的业务活动产生的合理费用。个人消费、未经审批的礼品和违反法律法规的支出不属于可报销范围。

## 二、申请材料

报销人需要提交费用明细、合规发票、审批记录和必要的业务说明。电子发票应上传原始文件，截图不能替代发票原件。

## 三、审批流程

员工提交后由直属主管审核业务真实性，财务审核票据和标准，超过部门额度的申请需要追加负责人审批。审批完成后进入付款队列。

## 四、时限与异常

费用原则上应在发生后一个月内提交。发票遗失、超标准或无法取得审批记录时，应在提交前联系财务说明情况，不得拆分单据绕过审批。
