# 并夕夕 商品搜索与筛选指南

## 一、搜索功能

### 1.1 关键词搜索
在首页搜索框输入商品关键词，平台将通过语义理解+销量排序自动推荐结果。支持以下搜索方式：
- 商品名称搜索（如"运动鞋"、"蓝牙耳机"）
- 品牌搜索（如"Nike"、"小米"）
- 型号搜索（如"iPhone 15 Pro"、"AirPods Pro 2"）
- 模糊搜索（如"夏天穿的薄裤子"）

### 1.2 图片搜索
支持以图搜货功能。上传商品图片或拍照，系统自动识别商品类别并匹配相似商品。识别准确率约85%，更适用于服饰、美妆等品类。

### 1.3 语音搜索
在移动端App支持语音输入搜索关键词。支持普通话和部分方言，嘈杂环境建议使用文字输入。

## 二、筛选与排序

### 2.1 筛选条件
搜索结果可按以下维度筛选：
- **价格区间**：自定义最低价和最高价
- **品牌**：勾选特定品牌
- **尺码/规格**：如鞋码、衣服尺码、颜色
- **服务标签**：顺丰包邮、24小时发货、七天无理由、正品保证
- **好评率**：4星以上、4.5星以上

### 2.2 排序方式
- **综合排序**（默认）：综合考虑销量、好评率、店铺评分、价格
- **销量优先**：按近30天确认收货数量降序
- **价格升序/降序**：按实付价排序（不含运费）
- **好评率优先**：按好评率降序（需评价数>=10条）
- **新品优先**：按上架时间降序

## 三、商品详情

### 3.1 SKU选择
部分商品有多种规格（颜色、尺码、配置），需选择SKU后才能看到对应价格和库存。SKU库存不足时显示"暂时缺货"。

### 3.2 价格说明
商品详情页显示的价格为当前SKU的到手价（已含店铺折扣，不含平台券）。划线价为品牌方建议零售价或历史最高价，非实际成交价。

### 3.3 评价系统
- 全部评价：默认按时间倒序展示
- 追评：购买后90天内可追加评价
- 晒图/视频评价：含图片或视频的评价会标注
- 好评率计算：近180天有效评价中4星及以上占比

## 四、收藏与比较

### 4.1 商品收藏
点击商品详情页的星形图标即可收藏。收藏夹可自定义分组（如"想买"、"对比中"）。收藏夹同步到账户，多设备可查看。

### 4.2 商品比较
在商品列表页勾选最多4个商品，点击「对比」可查看规格、价格、评价横向对比表。常用于购买前决策。

### 4.3 浏览历史
自动记录近30天浏览的商品（可在设置中关闭），方便回看之前感兴趣但未下单的商品。清除浏览历史后无法恢复。
