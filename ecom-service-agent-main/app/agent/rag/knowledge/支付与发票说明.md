# 并夕夕 支付与发票说明

## 一、支持的支付方式

### 1.1 在线支付
并夕夕支持以下支付方式：
- **微信支付**：扫码或JSAPI支付，单笔限额50000元
- **支付宝**：余额/余额宝/银行卡支付，单笔限额50000元
- **银联快捷支付**：支持62开头银联卡，单笔限额20000元
- **Apple Pay**：iOS设备专属，需绑定银联卡
- **云闪付**：支持所有银联卡，单笔限额10000元

### 1.2 分期支付
- **花呗分期**：支持3/6/12期，手续费率分别为2.5%/4.5%/8%
- **信用卡分期**：支持主流银行信用卡3/6/12/24期，手续费率由发卡行决定
- **并夕夕白条**：平台自有信用支付产品，首单免息3期，正常费率0.5%/期

### 1.3 不支持方式
- 货到付款（暂停服务）
- 境外信用卡（Visa/Mastercard暂不支持直接支付）
- 虚拟货币
- 银行转账汇款

## 二、支付安全

### 2.1 支付保护
所有在线支付均通过PCI-DSS认证的支付网关处理，并夕夕不会存储您的银行卡CVV码和完整卡号。支付过程中如遇异常扣款，请立即联系客服。

### 2.2 支付限额
为保障资金安全，新注册用户前7天单笔支付限额2000元，日累计限额5000元。实名认证后自动解除限额。企业账户限额请联系客户经理单独设置。

### 2.3 支付密码
建议设置独立的支付密码（不与登录密码相同），并开启指纹/面容支付验证。连续5次输入错误支付密码将冻结账户2小时。

## 三、发票服务

### 3.1 发票类型
- **电子普通发票**：免费，下单时勾选即可，开具后发送至注册邮箱和站内信
- **纸质普通发票**：满500元免费，不满收取10元工本费+快递费
- **增值税专用发票**：企业用户完成资质认证后可申请，24小时内审核

### 3.2 发票内容
默认开具「商品明细」发票，如实列出商品名称和数量。如需开具「办公用品」「耗材」等汇总名称，请在备注中说明。增值税专票必须开具明细。

### 3.3 发票修改与补开
- 未开具：在订单详情页直接修改发票抬头
- 已开具：电子发票可在30天内申请冲红重开（限1次）
- 纸质发票：签收后7天内可申请换开，需退回原发票

### 3.4 发票时效
- 电子发票：确认收货后1-3个工作日开具
- 纸质发票：确认收货后3-5个工作日寄出
- 增值税专票：确认收货后5-7个工作日寄出
