# 并夕夕 投诉与维权指南

## 一、投诉渠道

### 1.1 在线投诉
- **订单投诉**：在订单详情页点击「申请售后→我要投诉」，选择投诉类型并描述问题
- **客服投诉**：联系客服时明确表示要投诉，客服会创建投诉工单并转交投诉处理专员
- **商家投诉**：在商品详情页点击「举报商家」，适用于商家违规行为

### 1.2 投诉处理时效
- 普通投诉：24小时内响应，3个工作日内给出处理结果
- 紧急投诉（涉及人身安全、大额资金）：2小时内响应，1个工作日内给出初步结果
- 投诉升级：对处理结果不满可申请升级，由高级专员复核

## 二、投诉类型

### 2.1 商品投诉
- 假货投诉：需提供商品照片+疑似假货证据，经品牌方鉴定确认假货后赔付订单金额3倍（最低500元）
- 质量问题投诉：商品破损、功能故障、与描述不符等
- 少发/漏发投诉：需提供开箱视频或照片

### 2.2 物流投诉
- 虚假发货：商家上传物流单号后48小时无揽件记录
- 物流丢失：快递公司确认丢件
- 暴力运输：包装严重破损

### 2.3 服务投诉
- 客服态度投诉
- 商家拒绝售后
- 商家骚扰威胁

## 三、赔付标准

### 3.1 假货赔付
经品牌方鉴定为假货的商品，按订单实付金额的3倍赔偿（最低500元）。鉴定费用由平台承担。同一用户同一商家一年内假货赔付上限2次。

### 3.2 延迟发货赔付
- 普通商品超72小时未发货：赔偿订单金额的5%（最低5元，最高50元）
- 预售商品超约定发货时间：赔偿订单金额的10%（最低10元，最高100元）
- 虚假发货：赔偿订单金额的30%（最低10元，最高200元）

### 3.3 物流超时赔付
配送超过承诺时效（以订单详情页显示为准），每超1天赔偿5元（上限30元）。遇不可抗力（自然灾害、疫情管控）除外。

## 四、维权方式

### 4.1 平台维权
通过并夕夕客服投诉→处理→升级→仲裁的流程维权。平台仲裁结果为最终结果，双方需遵守。

### 4.2 外部维权
- 12315热线或www.12315.cn在线投诉
- 消费者协会调解
- 互联网法院在线诉讼（标的额5万元以下适用小额诉讼程序）

### 4.3 维权时效
- 商品投诉：签收后15天内（质量问题），或发现假货后90天内
- 服务投诉：事发后30天内
- 法律诉讼时效：知道权利受损之日起3年内
