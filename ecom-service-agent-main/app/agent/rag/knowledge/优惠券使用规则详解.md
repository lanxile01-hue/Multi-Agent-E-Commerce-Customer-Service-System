# 并夕夕 优惠券使用规则详解

## 一、券类型与编码体系

并夕夕优惠券按来源分为四类，每类有独立编码规则：

平台券：PLT-{类型}-{面值}-{批次}。类型包括 FULL(满减券)、NO(无门槛券)、CAT(品类券)。
店铺券：SHP-{店铺ID}-{类型}-{面值}。
活动券：EVT-{活动代码}-{面值}。如 EVT-618-30 表示 618 活动专享满减券。
补偿券：CMP-{原因代码}-{面值}。如 CMP-LOSS-20 表示丢件补偿 20 元券。

## 三、券叠加规则

同类型券每单限用 1 张（先取面值最大，面值相同先取即将过期的）。
不同类型券可叠加使用：平台券 + 店铺券 + 活动券 最多 3 张。
叠加计算顺序：先减平台券 → 再减店铺券 → 最后减活动券。
券后实付金额低于 0 元时，按 0.01 元结算（最低支付门槛）。

## 四、券退还规则

订单全额退款：已使用的优惠券退回用户账户，有效期不变。
订单部分退款：券不退回。
订单取消（未支付）：券退回，有效期不变。
券过期前 24 小时：系统推送提醒，用户可选择转赠给好友（仅限无门槛券）。
