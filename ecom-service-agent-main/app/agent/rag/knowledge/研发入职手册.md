# 研发入职手册

## 一、账号与权限

入职当天由直属主管提交统一身份平台、代码仓库、制品库和项目管理系统的权限申请。申请时必须填写员工编号、所属部门、项目组和权限期限，禁止借用他人账号。

## 二、本地环境

后端项目统一使用 Python 3.12 或团队批准的版本，依赖必须安装在项目虚拟环境中。Node.js 项目使用仓库锁定的包管理器和 lockfile。不得把密钥、生产配置或个人令牌提交到代码仓库。

## 三、开发流程

新需求先关联工单，再创建短分支。提交信息使用“类型: 简要描述”格式，例如 `feat: add document ingestion`。合并前至少需要一名同事完成代码评审，并通过单元测试和静态检查。

## 四、常见问题

如果本地依赖安装失败，先确认 Python/Node 版本和 lockfile 是否一致，再清理项目缓存并重新安装。仍无法解决时，在研发群提交最小复现、错误日志和环境信息。
