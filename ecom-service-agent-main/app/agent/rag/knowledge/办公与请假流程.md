# 办公与请假流程

## 一、请假申请

员工应通过人事系统提交请假类型、起止时间和工作交接。原则上应提前申请；突发情况先通知直属主管，再补充系统记录。

## 二、审批规则

直属主管负责确认业务安排，连续休假或特殊假期按照人事系统配置追加审批。未经审批的缺勤不能直接视为已批准休假。

## 三、远程办公

远程办公需要提前获得团队负责人批准，并确保使用公司设备、受控网络和多因素认证。涉及敏感数据的操作应在公司批准的安全环境中完成。

## 四、工作交接

休假前需要同步进行中的任务、紧急联系人、截止时间和风险事项。交接材料不得包含未脱敏的客户隐私或密钥信息。
