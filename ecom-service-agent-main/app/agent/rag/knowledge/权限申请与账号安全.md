# 权限申请与账号安全

## 一、最小权限原则

系统权限按岗位和工作需要授予，默认不给予生产写权限。临时权限必须设置失效时间，任务完成后立即回收。

## 二、申请与审批

权限申请必须关联工单，写明资源、操作类型、使用原因和有效期。资源负责人审批业务必要性，安全团队负责高风险权限复核。

## 三、账号安全

账号必须启用多因素认证，禁止共享账号和通过聊天工具传递令牌。发现令牌泄露时，应立即撤销并报告安全团队。

## 四、人员变更

转岗、离职和外包合同到期时，管理系统应在生效时间回收原有权限。项目负责人需要复核共享账号、机器人账号和定时任务凭证。
