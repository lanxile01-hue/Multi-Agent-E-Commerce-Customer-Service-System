# 并夕夕 优惠券使用规则

## 一、优惠券类型

### 1.1 平台券
由并夕夕平台发放，全场通用（部分特殊商品除外），可在结算页面选择使用。
- **满减券**：满指定金额可减，如满199减30、满499减80
- **无门槛券**：无最低消费限制，直接抵扣
- **折扣券**：按比例折扣，如8.8折券（上限50元）

### 1.2 店铺券
由特定店铺发放，仅限该店铺商品使用。可与平台券叠加使用，叠加顺序为先店铺券后平台券。

### 1.3 品类券
限特定商品品类使用，如「数码品类券」「服饰品类券」「美妆品类券」。品类券可与平台券叠加。

### 1.4 新人专享券
注册7天内有效，包括30元无门槛券和首单满99减20券。每个设备仅限领取1次。

## 二、获取方式

### 2.1 免费领取
- **每日签到**：连续签到7天可额外获得满99减5元券
- **领券中心**：每日10点限量发放，先到先得
- **活动会场**：大促期间（618、双11、双12）可领多张品类券
- **会员专属**：根据会员等级每月自动发放对应额度优惠券

### 2.2 积分兑换
使用积分在「积分商城」兑换优惠券。兑换比例约100积分=1元，不同面额券所需积分不同。积分兑换的优惠券有效期30天。

### 2.3 邀请有礼
邀请新用户注册并完成首单，邀请人和被邀请人各得20元无门槛券。邀请奖励券有效期15天。

## 三、使用规则

### 3.1 叠加规则
- 平台券 + 店铺券 + 品类券可叠加使用（最多3张）
- 同类型优惠券不可叠加（如两张平台券选其一）
- 优惠券与会员折扣、积分抵扣可同时使用
- 优惠券优先于积分抵扣和会员折扣计算

### 3.2 排除商品
以下商品类型不可使用优惠券：
- 秒杀/限时特价商品
- 虚拟商品（话费充值、游戏点卡）
- 黄金、珠宝、投资金条
- 部分预售商品（标注"不参与优惠"）

### 3.3 有效期
- 平台券：领取后7-30天有效（具体见券面）
- 积分兑换券：固定30天有效
- 新人券：注册后7天有效
- 过期券不补发、不延期

### 3.4 退款处理
- 全额退款：已使用的优惠券按比例退回（剩余有效期>3天则恢复）
- 部分退款：优惠券不退回，按实际支付金额和退款商品占比退款
- 使用多张券：按券面金额比例退还
