# 并夕夕 售后保障政策

## 一、商品保修服务

### 1.1 保修范围
并夕夕平台所售3C数码、家用电器、办公设备类商品，均享受国家三包政策。保修期内出现非人为故障，由品牌方授权售后中心提供免费维修服务。

### 1.2 保修期限
- 手机/平板/电脑：整机保修1年，主要部件（主板、屏幕、电池）保修2年
- 大家电（冰箱、洗衣机、空调）：整机保修1年，压缩机保修3年
- 小家电（电饭煲、微波炉、吸尘器）：整机保修1年
- 办公设备（打印机、投影仪）：整机保修1年

### 1.3 保修凭证
申请保修时需提供以下任一凭证：
- 并夕夕电子订单详情页（含订单号、商品名称、购买日期）
- 品牌方电子保修卡（需在购买后30天内激活）
- 商品机身序列号（部分品牌支持无纸化保修）

### 1.4 不保修情形
以下情况不在免费保修范围内：
- 超过保修期限
- 人为损坏（进水、摔落、私自拆修、不当使用）
- 不可抗力因素（火灾、水灾、雷击）
- 消耗性配件（电池正常衰减、滤网、灯泡）

## 二、延长保修服务

### 2.1 延保购买
在商品购买后30天内，可购买「并夕夕延保服务」。延保费用按商品价格的5%-8%计算，可在商品详情页直接购买。

### 2.2 延保覆盖
延长保修在原厂保修期结束后继续生效，覆盖所有原厂保修范围内的故障。延保年限可选1年或2年，不同商品类型可选年限不同。

### 2.3 延保理赔
延保期内出现故障，直接联系并夕夕客服，由平台安排上门取件或指定维修点。维修周期一般3-5个工作日，期间如需代用机，可申请「维修备用机」服务（限手机/平板类）。

## 三、意外保障服务

### 3.1 碎屏保
手机、平板类商品可单独购买「碎屏保」，年费89元起。保障期间内，屏幕碎裂可享受一次免费维修或半价换新。碎屏保在购买商品时或收货后7天内可加购。

### 3.2 全保服务
针对高价值商品（单价3000元以上），提供「全保服务」，年费按商品价格3%计算。保障范围包括意外跌落、进水、挤压等非故意损坏，每年限理赔2次，每次自付比例10%。

## 四、延保与全保退款

### 4.1 未使用退款
延保或全保服务在购买后30天内未使用，可全额退款。超过30天后按剩余天数比例退款。

### 4.2 商品退货时自动退款
如果购买了延保的主商品发生退货，对应的延保费用将自动全额退还至原支付账户，无需单独申请。
